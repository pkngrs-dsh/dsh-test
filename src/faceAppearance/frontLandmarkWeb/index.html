EXPERIMENT NOTES

实验信息

两侧使用同一坐标系、镜头和光照。客户端分支共用原融合贴图与原有 UV；几何校正后尚未重投影纹理，已有融合错位可能仍然存在。原始 UFF 分支使用其自身 UV 与贴图，仅作参考。交互窗口显示皮肤，不含眼球和附件；照片叠图使用该次重建保存的相机。

自动关键点不是人工真值。正面误差减小只说明更贴合这些观测，不能单独证明三维形状、侧面或动画质量。

后处理保留直接配准得到的局部几何，通过位移平滑控制形变；没有拉回原模板的形状先验。低置信度点和不支持的对应应跳过，具体以报告为准。

分区后处理按嘴部、画面左眼、画面右眼依次拟合，各部位单独回退；显示的比例是该阶段保留的位移。某阶段为 0 时不应用这一步，已通过的前序调整仍保留。未回退的完整拟合仅作诊断，可能有新增穿插。

配准与后处理范围

“处理前”为无模板形状先验、固定接口的直接配准；“分区后处理”为嘴 → 画面左眼 → 画面右眼的分阶段候选；“同时拟合 / 整体回退”为嘴眼同时优化后统一缩小位移的对照；“未回退”为完整位移的诊断版本。固定深度指保存的正面相机坐标中的深度，旋转到侧面仍可能观察到轮廓变化。

每个阶段均相对最初“处理前”重新检查局部几何、固定接口、正面深度与累计位移。穿插检查仅限制新增的最终非邻接相交面片对：已有自交未消除，同一面片对的相交严重程度及运动过程中的穿插未获保证。当前实验没有替换远程服务。
